# Explorer 提示詞模板

用這個模板構建每個 explorer 子代理的提示詞。填好佔位符。

---

其他 explorer 正在並行調查同一子系統的不同切片。不要試圖覆蓋全部內容。聚焦分配給你的角度，深入下去。

只讀。不要修改、建立或刪除任何檔案。

## 問題

> {QUESTION}

## 你的探查角度

{EXPLORATION_ANGLE}

## 輸出

### 找到的元件
關鍵的型別、服務、類和抽象。每一項給出：名稱、檔案路徑，以及一句話說明它做什麼。

### 流程
逐步說明執行流程。每一步給出：執行的是哪個函式/方法、位於哪個檔案、做什麼、接下來呼叫什麼。包含步驟之間流動的資料。

### 讀取的檔案
你在探查過程中讀過的每個檔案，方便 explainer 引用。

### 邊界
這個子系統與程式碼庫其他部分的連線處。輸入與輸出。

### 不顯眼之處
任何令人意外、有歷史原因或容易搞錯的地方。看起來應該按某種方式工作、實際卻按另一種方式工作的東西。

### 未解決的問題
任何你沒能完全追蹤或理解的地方。如實說明缺口。
